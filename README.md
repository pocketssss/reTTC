# Статический реверс-инжиниринг TTC

В репозитории разобрано приложение [Time To Capture (TTC)](https://timetocapture.ru/).

Анализ выполнен 25 ноября 2026 года. В коде приложение обозначено как CaptBot / TTC версии `2.9.13`. Ресурс версии файла содержит значение `0.0.0.0`.

В папке находятся 106 именованных типов верхнего уровня, 107 C#-файлов с учётом атрибутов сборки, пять исходных встроенных ресурсов и проект, созданный декомпилятором. Структура каталогов восстановлена по пространствам имён и типам. Исходная структура решения, авторские комментарии и имена исходных файлов недоступны.

## Повторение статического экспорта

Скрипты читают файл через API для PE и метаданных. В ходе анализа образец не запускался и не загружался как исполняемая сборка. Обращения к его серверу лицензирования не выполнялись. Предоставленный лицензионный ключ не использовался.

Проверенное окружение состояло из PowerShell `7.6.9`, встроенного в него Roslyn `5.0.0.0` и ICSharpCode.Decompiler `8.2.0.7535` с сопутствующими зависимостями. Укажите пути к образцу и доверенной библиотеке анализа на своём компьютере. Команды выполняются из корня этой папки с новым каталогом вывода.

```powershell
$sample = 'C:\Samples\TTC.exe'
$decompiler = 'C:\Tools\ILSpy\ICSharpCode.Decompiler.dll'

.\tools\Export-Static.ps1 -InputPath $sample -DecompilerPath $decompiler -OutputDirectory .\scratch\reexport\src
.\tools\Verify-StaticExport.ps1 -InputPath $sample -DecompilerPath $decompiler -RepositoryDirectory .\scratch\reexport
```

Экспортёр проверяет зафиксированный хеш образца и отказывается перезаписывать существующий каталог. Для другого входного файла требуется новый анализ перед изменением ожидаемого хеша.

## Выполненные проверки

- Подтверждено наличие файлов для всех 106 именованных типов верхнего уровня из метаданных, за исключением типов, созданных компилятором.
- Содержимое пяти встроенных ресурсов сопоставлено с входным PE по SHA-256. Все ресурсы совпали.
- Все 107 C#-файлов разобраны Roslyn в режиме C# 11. Синтаксических ошибок не обнаружено.
- Тексты для публикации проверены по выбранным шаблонам лицензионных ключей, токенов доступа, закрытых ключей и персональных путей. Полные совпадения с форматом лицензии обнаружены только в исходных подсказках интерфейса `CAPT-XXXX-XXXX-XXXX-XXXX`.
- Подтверждено отсутствие в папке для публикации EXE, DLL, PDB, файлов ключей и личного состояния приложения.

## Ограничения сборки и интерпретации

Созданный декомпилятором `TTC.csproj` нацелен на `net40`. Эта настройка определена декомпилятором, исходная конфигурация сборки недоступна. Проверка синтаксиса не подтверждает успешную сборку или эквивалентность поведения. Восстановленный проект не компилировался и не проверялся запуском.

Имена локальных переменных, восстановление лямбда-выражений и форматирование могут отличаться от авторского исходного кода. Выводы отчёта основаны на восстановленных ветвлениях, вызовах и константах. Серверная авторизация, успешность отправки данных, работа автоматизации и реакция античита требуют отдельных наблюдений.

Исполняемые образцы, личные настройки и учётные данные следует хранить за пределами папки для публикации. В `.gitignore` включены распространённые файлы образцов, состояния приложения и результатов сборки.
