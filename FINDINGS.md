# Результаты статического анализа TTC

Разбор приложения [Time To Capture (TTC)](https://timetocapture.ru/).

## Область анализа и доказательства

Все выводы относятся к образцу с SHA-256 `77EA21DB08F93892C139A5A5DD5C1265444D070FDCA61F3F02E2E6ED9AF4FFE7`, в коде которого указана версия `2.9.13`. Анализ выполнен 25 ноября 2026 года по исходникам, разбитым на файлы в этой папке. Образец не запускался. Проверки лицензии, запросы к сервису, создание задач планировщика и захват пакетов в ходе анализа не выполнялись.

Уровень риска представляет собой оценку описанных последствий. Последствия на работающей системе и принятие запросов удалёнными сервисами остаются непроверенными.

## F01. Сброс фильтров pktmon

Средний риск для надёжности.

Приложение включает монитор пакетов Windows, когда не видит игровые пакеты через raw-сокеты. Перед установкой фильтров TTC метод `PktMonCapture.Start` вызывает `pktmon stop` и `pktmon filter remove`. Метод `Cleanup` повторяет остановку захвата и удаление фильтров. Принадлежность уже активного захвата и его фильтров в этих ветвях не проверяется. [Start](src/CaptBot/PktMonCapture.cs#L76), [Cleanup](src/CaptBot/PktMonCapture.cs#L206), [выбор резервного способа захвата](src/CaptBot/NetWatch.cs#L895).

Согласно документации Microsoft, `pktmon filter remove` удаляет все фильтры пакетов, а `pktmon stop` останавливает сбор данных. Поэтому при входе TTC в эту ветвь или выходе из неё может прерваться уже выполняемая диагностика и сброситься конфигурация её фильтров. [Документация Microsoft по фильтрам](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/pktmon-filter), [справочник команд Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/pktmon).

Исправление должно учитывать владельца существующего захвата, предотвращать перехват чужого сеанса и сохранять общую конфигурацию при ошибках инициализации и завершении работы. Для проверки следует создать отдельный диагностический сеанс, вызвать резервный путь TTC и сравнить состояние сеанса и фильтров до и после. Такая проверка не выполнялась.

## F02. Ключ в открытом JSON

Средний риск раскрытия ключа при локальном доступе.

После успешного ответа сервера лицензирования метод `License.Save` сериализует объект `Saved`, содержащий полный `Key`, в `license.dat` через `File.WriteAllText`. Обычно `AppPaths.Data` указывает на `%LOCALAPPDATA%\TTC`. При сохранении ключ не шифруется. [Поля кеша](src/CaptBot/License.cs#L17), [запись файла](src/CaptBot/License.cs#L106), [каталог данных](src/CaptBot/AppPaths.cs#L62).

Для раскрытия ключа нужен доступ на чтение к данным приложения текущего пользователя или их копии, например архиву для поддержки либо резервной копии. Приложение также проверяет HWID, поэтому возможность повторного использования извлечённого ключа на другом компьютере не подтверждена. [Вычисление HWID](src/CaptBot/License.cs#L43), [проверка привязки ответа](src/CaptBot/License.cs#L220).

Исправление должно защищать локальное хранилище ключа в контексте нужного пользователя Windows и сокращать распространение многократно используемого ключа. Проверка должна охватывать новые файлы состояния, материалы для поддержки, штатную повторную загрузку ключа и границы доступа между учётными записями. Личные файлы с лицензионными данными в ходе анализа не читались.

## F03. Автозапуск с повышенными правами

Средний риск, связанный с привилегиями и постоянным автозапуском.

Если `StartWithWindowsChosen` равен false, загрузка настроек устанавливает `StartWithWindows` в true. При включённой настройке инициализация интерфейса синхронизирует задачу планировщика. По умолчанию `LogonTask.Enable` использует `highest: true`, а создаваемый XML содержит запуск при входе в Windows, `HighestAvailable` и аргумент `--tray`. Обычный запуск программы также запрашивает права администратора. [Значение по умолчанию](src/CaptBot/Ui.cs#L2298), [синхронизация задачи](src/CaptBot/Ui.cs#L12215), [реализация задачи](src/CaptBot/LogonTask.cs#L14), [проверка прав администратора](src/CaptBot/Program.cs#L31).

Если задача успешно настроена и учётная запись имеет нужные права, при следующих входах в Windows приложение может запускаться с повышенными правами в трее. Это продлевает время работы и увеличивает привилегии наблюдения за пакетами и фонового взаимодействия с сервисом. Создаваемая задача видима в планировщике, в интерфейсе есть переключатель автозапуска. [XML задачи](src/CaptBot/LogonTask.cs#L140), [обработчик переключателя](src/CaptBot/Ui.cs#L12434).

Исправление должно включать постоянный автозапуск по явному выбору пользователя и изолировать операции, требующие повышения прав. Для проверки следует изучить настройки первого запуска, учётную запись, триггер и действие созданной задачи под обычной и административной учётными записями. Создание задачи не проверялось.

## F04. Ключ и HWID в телеметрии

Риск для конфиденциальности.

Обычный запуск включает телеметрию, а инициализация интерфейса вызывает `Telemetry.Start`. Стартовое событие содержит сведения об экране, операционной системе и версии CLR. В отправляемый объект входят полный сохранённый лицензионный ключ, вычисленный HWID, версия приложения и события из очереди. В восстановленном классе `Settings` отсутствует свойство отключения телеметрии. [Состояние при запуске](src/CaptBot/Program.cs#L20), [сведения об экране](src/CaptBot/Ui.cs#L2261), [событие окружения](src/CaptBot/Telemetry.cs#L151), [состав отправляемого объекта](src/CaptBot/Telemetry.cs#L848), [модель настроек](src/CaptBot/Settings.cs).

Диагностические тексты проходят очистку, которая маскирует строки в формате лицензионного ключа, адреса электронной почты, некоторые токены и локальные идентификаторы. Полные ключ и HWID отдельно добавляются в объект отправки. События направляются на `timetocapture.ru`, неотправленная очередь может сохраняться в `telemetry.queue`. [Очистка текстов](src/CaptBot/Telemetry.cs#L946), [локальная очередь](src/CaptBot/Telemetry.cs#L177), [HTTP-запрос](src/CaptBot/Telemetry.cs#L887).

Сервис может связывать полученную диагностику с лицензией и устойчивым идентификатором устройства. Фактическое получение данных, срок хранения и дальнейшее использование неизвестны. Исправление должно предусматривать документированный выбор пользователя, сокращение идентификаторов и отдельные полномочия для отправки телеметрии. Проверка должна исследовать отправляемые объекты в явно настроенном тестовом окружении и работу соответствующей настройки. Запросы в ходе анализа не отправлялись.

## F05. Отправка игровых данных

Риск для конфиденциальности и фоновой передачи данных.

Инициализация интерфейса запускает `NetWatch`. При наличии выбранного сервера и сохранённого ключа таймер забирает собранные игровые данные и передаёт их в `War.ReportNet`. Отчёт может включать владельцев зон, названия и ID семей, лимиты атак и защит, время и результаты каптов. Данные отправляются на `/api/v1/war/net` сервиса TTC. [Инициализация](src/CaptBot/Ui.cs#L1090), [запуск сбора](src/CaptBot/Ui.cs#L7452), [условия отправки](src/CaptBot/Ui.cs#L7478), [сериализуемые поля](src/CaptBot/War.cs#L206).

Собранное состояние игры становится доступно серверу TTC. Этот процесс может продолжаться при работе приложения в трее. В коде предусмотрены сообщения журнала об общей карте и проверка, предотвращающая смешивание данных разных серверов. [Сообщение в журнале приложения](src/CaptBot/Ui.cs#L7455), [проверка сервера](src/CaptBot/Ui.cs#L7490).

Исправление должно позволять отдельно настраивать фоновую передачу данных, описывать отправляемые поля и определять сроки хранения. Проверка должна охватывать включение и отключение передачи, работу в трее, переключение сервера и завершение приложения с использованием тестового адреса сервиса. Фактическая передача и дальнейшая публикация данных серверной частью остаются непроверенными.

## Другие восстановленные функции

Перед записью нового EXE механизм обновления проверяет подписанные сведения, привязку к запросу, ожидаемый размер и SHA-256. Автоматизация браузера использует Chromium DevTools Protocol и профиль, управляемый TTC. В коде также есть перенос данных из старого профиля `DiscordImageReader`. Эти операции выделены для изучения, дополнительные уязвимости в них не установлены. [Обновление](src/CaptBot/Updater.cs#L44), [запуск браузера](src/CaptBot/CdpBrowser.cs#L110), [перенос старого профиля](src/CaptBot/CdpBrowser.cs#L183).
